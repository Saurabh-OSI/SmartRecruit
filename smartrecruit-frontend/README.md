# SmartRecruit Frontend

This folder contains the React + Vite frontend for SmartRecruit.

## Scripts

- `npm run dev` starts the local development server
- `npm run build` creates a production build
- `npm run preview` previews the production build locally
- `npm run lint` runs ESLint

## App Routes

- `/` login
- `/register` registration
- `/dashboard` recruitment dashboard
- `/jobs` jobs listing and management
- `/profile` candidate profile
- `/applications` application tracking
- `/interviews` interview management

## API Base URL

The frontend is configured to call the backend at `http://localhost:8080/api`.

See the repository root `README.md` for the full project setup.
